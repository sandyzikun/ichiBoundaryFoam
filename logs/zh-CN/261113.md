# `ichiBoundaryFoam` 开发记录：圆柱边界法线速度剖面

日期：2026-11-13

## 今日结论

今天在现有 `ichiwaveplot variables` 中加入了 `--cylbound`，开始使用
`system/functions/samplingLines1D` 中四条垂直于圆柱侧壁、沿径向向外的
采样线，诊断 BF-1 与旧 cell-based IBM-R1 的近壁速度分布：

* `boundaryLineCylinderXNeg`；
* `boundaryLineCylinderXPos`；
* `boundaryLineCylinderYNeg`；
* `boundaryLineCylinderYPos`。

新诊断将流体速度转换到局部圆柱坐标，并按 wave cycle 与 phase 绘制法向、
周向、轴向及两种速度模长。IBM-R1 在 $Y^+$/$Y^-$ 两侧表现出很好的镜像
对称性；解析表面附近的法向残差约为 $O(10^{-3})\,\mathrm{m/s}$，总相对
速度约为 $O(10^{-2})\,\mathrm{m/s}$，主要由切向分量贡献。这与此前 solver
日志中“tangential slip 明显大于 normal slip”的判断一致。

BF-1 在真实 wall patch 上严格满足零速度，但其首层流体速度在离壁数毫米内
迅速增大。IBM-R1 的离壁速度较低且恢复更平滑，但这不能解释为 IBM 比 BF
更准确；更可能是 diffuse volume forcing 形成了较厚的数值约束层，并可能
过度抑制真实流体速度。

## `--cylbound` 的实现

修改位于：

```text
~/slurm_of/waves2-3d/ichi-utils/ichiwaveplot/
```

涉及：

* `src/ichiwaveplot/plotting/variables.py`；
* `src/ichiwaveplot/defaults/ichiwaveplotrc.yaml`；
* CLI 与局部坐标分解测试。

调用方式为：

```bash
ichiwaveplot variables --case CASE --cylbound
```

每条法线、每个配置周期生成一张五个 axes 共用横轴的图片。横轴为距解析
壁面的距离 $d$，五个纵轴依次为：

$$
u_n=\boldsymbol u_r\cdot\boldsymbol e_n,
$$

$$
u_\theta=\boldsymbol u_r\cdot\boldsymbol e_\theta,
$$

$$
u_z=\boldsymbol u_r\cdot\boldsymbol e_z,
$$

$$
|\boldsymbol u_t|=\sqrt{u_\theta^2+u_z^2},
$$

以及

$$
|\boldsymbol u_r|
=\sqrt{u_n^2+u_\theta^2+u_z^2}.
$$

其中

$$
\boldsymbol u_r=\boldsymbol U-\boldsymbol U_b,
\qquad
\boldsymbol e_\theta=\boldsymbol e_z\times\boldsymbol e_n.
$$

当前 BF-1 与 IBM-R1 的结构均静止，所以配置中的
`body_velocity = (0,0,0)`。未来进入 prescribed-motion 或双向 FSI 后，
应改为从 sampling output 读取 `immersedSurfaceVelocity` 或等价的真实结构
局部速度，不能继续假定 $\boldsymbol U_b=0$。

OpenFOAM sampled-set 在 `axis x` 或 `axis y` 下通常只写相应的单一空间
坐标。因此默认 YAML 为每条线分别记录：

* `coordinate: x|y`；
* `wall_coordinate`；
* 三维外法向 `normal`。

程序由该坐标计算有符号外法向距离，并未要求 CSV 同时包含 `x/y/z`。首版
实现通过了现有测试及新增方向分解测试：

```text
28 passed
```

## IBM-R1 的 $Y^+$/$Y^-$ 侧面结果

对 cycle 121 的两条侧面法线，解析壁面 $d=0$ 处的结果范围约为：

| 指标 | 数值范围 |
| --- | ---: |
| $|u_n|$ | $4.4\times10^{-4}$--$2.5\times10^{-3}\,\mathrm{m/s}$ |
| $|\boldsymbol u_r|$ | $0.013$--$0.055\,\mathrm{m/s}$ |
| $u_z$ | $-0.012$--$0.015\,\mathrm{m/s}$ |

两侧具有以下对应关系：

* $u_n$ 基本相同；
* $u_z$ 基本相同；
* $u_\theta$ 大小相同、符号相反；
* $|\boldsymbol u_t|$ 与 $|\boldsymbol u_r|$ 几乎重合。

周向符号翻转来自局部坐标定义，而不是两侧解互相矛盾：

```text
YPos: e_n = +e_y, e_theta = -e_x
YNeg: e_n = -e_y, e_theta = +e_x
```

因此同一个全局 $U_x$ 在两条侧线上会产生符号相反的 $u_\theta$。两侧
magnitude 的差异约为 $O(10^{-4})\,\mathrm{m/s}$，支持当前 SDF 几何、
forcing 与 sampling transformation 保持良好对称性。

这些法线只位于 $z=0.5\,\mathrm m$ 的纯水区，不能替代 solver 对完整圆柱
SDF band 的全域最大 slip。此前约 $0.4$--$0.6\,\mathrm{m/s}$ 的全域
surface-band 峰值可能位于自由液面、气相、柱顶、caps 或其他网格相位不利的
位置；中部侧线给出的 $O(10^{-2})\,\mathrm{m/s}$ 只代表局部结果。

## 与 BF-1 的比较

BF-1 使用真实 O-grid monopile patch、固定值 `U=0` 和正常的
`kOmegaSST` wall-distance/wall-function 路线。其采样在 $d=0$ 处严格为零，
但通过 `cellPoint` 从壁面到首层流体自由度插值后，速度在前几毫米迅速增加。

以 $\psi=315^\circ$ 的 YNeg 线为例：

| $d$ [m] | BF-1 $|\boldsymbol u_r|$ [m/s] | IBM-R1 $|\boldsymbol u_r|$ [m/s] |
| ---: | ---: | ---: |
| 0 | 0 | 0.0550 |
| 0.001 | 0.1048 | 0.0756 |
| 0.002 | 0.2095 | 0.0962 |
| 0.004 | 0.4191 | 0.1374 |
| 0.010 | 0.3642 | 0.2360 |

所以必须区分两个指标：

1. **wall constraint error**：BF 在真实 wall 上严格为零；IBM 在解析表面
   仍有 $O(10^{-2})\,\mathrm{m/s}$ residual；
2. **off-wall velocity profile**：IBM 在若干毫米内给出更低、更平滑的速度，
   但这可能是 diffuse forcing 的数值扩散或 over-forcing。

当前 BF 与 IBM 还使用不同的近壁物理和离散处理：

```text
BF-1:
real wall patch + mesh wall distance + kOmegaSST wall functions

IBM-R1:
cell-based diffuse volume forcing + ordinary bulk kOmegaSST
```

因此“IBM 离壁速度更低”不等价于“IBM 边界层更准确”。尤其在当前
immersed wall treatment 尚未通过验证时，IBM 的 wall shear、湍流生产与载荷
不能由这组 profile 单独确认。

## Cycle 编号的时间语义

当前 `--vprof` 和 `--cylbound` 沿用：

$$
t=t_\mathrm{ref}
+\left(N_\mathrm{cycle}+\frac{\psi}{360^\circ}\right)T.
$$

在 $t_\mathrm{ref}=0$、$T=2\,\mathrm s$ 时，`cycle 121` 实际读取：

```text
242.00 s <= t <= 243.75 s
```

而不是从 $240\,\mathrm s$ 开始。如果项目希望“第 121 个周期”表示
$240$--$242\,\mathrm s$，则应改为使用 $N_\mathrm{cycle}-1$。在修改前，
图名中的 cycle 应视为当前程序的整数周期坐标，而非从 1 开始计数的人类序号。

## 当前判断与下一步

本轮法线采样支持以下判断：

* IBM-R1 的侧面 no-penetration residual 已较小；
* 剩余 wall residual 主要由 tangential components 构成；
* $Y^+$/$Y^-$ 两侧的镜像对称性良好；
* IBM 的速度抑制层比 BF 的采样 profile 更厚、更平滑；
* 该平滑不能作为 IBM 优于 body-fitted 方法的证据。

后续比较应：

1. 在图中标记 BF 第一层 cell centre、IBM forcing cells、SDF 零面及局部
   网格尺度；
2. 同时比较 wall residual 与 $d>0$ 的 off-wall profile，不把二者混为一个
   no-slip 指标；
3. 增加 $d/D$ 表示，并在 IBM wall shear 可信前暂不使用 $y^+$；
4. 检查 $X^+$/$X^-$ 法线及自由液面、柱顶附近是否对应全域最大 slip；
5. 通过网格敏感性、载荷、压力和 BF 对照判断 IBM 的低离壁速度是合理响应
   还是 over-forcing；
6. 在 marker-based 路线中继续把表面 residual、插值/展布和压力投影作为统一
   离散问题验证。

当前最稳妥的表述是：旧 cell-based IBM 已能产生长期有界、相位重复且几何
对称的侧面速度 profile，但解析表面的 tangential no-slip 尚未严格满足；其
较厚的低速区仍需与真实 BF boundary layer 和网格收敛结果区分。
