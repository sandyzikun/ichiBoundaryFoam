# `ichiBoundaryFoam` 开发进展与下一阶段路线（截至 2026-11-12）

## 1. 当前目标

`ichiBoundaryFoam` 的目标是在 OpenFOAM-com v2312 的双相 VoF
框架中加入可运动固体的 immersed boundary method（IBM），最终用于波浪与
主动运动 monopile 的单向或双向 WSI/FSI，并为以后加入 Lagrangian DPM
保留接口。

目前应把项目状态概括为：**双相 VoF 主体和 prescribed-motion geometry
已经可用；旧 cell-based IBM 已形成稳定的研究基线，但 immersed boundary
上的速度约束精度，特别是 slip，尚未达到可作为最终 benchmark 的程度。**

## 2. 已完成的基础能力

### 2.1 双相 VoF 与波浪模拟

* 建立了接近 `interFoam` 的 VoF、PIMPLE、湍流与波浪求解流程。
* 已用 dam-break 和 Stokes I/II/V wave(s) 与原生 `interFoam` 做过回归比较。
* 在 IBM 关闭时，可在 body-fitted 网格上运行 Stokes II wave(s)、
  `kOmegaSST` 和固定圆柱算例；BF-1 被保留为主要 body-fitted 对照。
* 固定 `deltaT`、相分数、Courant No.、液面、速度和压力等诊断均已纳入
  现有算例与 `ichiwaveplot` 工作流。

### 2.2 几何、SDF 与运动结构

* 固体几何可由 case 字典配置，而非硬编码在 solver 中。
* 可实时计算 signed distance function（SDF），并由 SDF 获得固体内外、
  距离和法向等几何信息。
* 已支持静止结构和 prescribed translation/rotation；M1a/V1m 等实验说明
  运动学更新和流场时间推进能够耦合运行。
* SDF 今后仍会用于几何定位、法向、距离以及 marker 生成；转向
  marker-based coupling 并不意味着废弃 SDF。

### 2.3 旧 cell-based IBM 基线

现有成熟度最高的配置为：

```text
couplingMethod  cellBased;
forcingMethod   diffuseVelocity;
MDF             enabled;
PPMDF           disabled;
IBM-aware projection disabled;
new turbwall treatment disabled;
```

该路线已经具备：

* 基于 SDF/solid fraction 的 diffuse interface 速度约束；
* multi-direct forcing（MDF）；
* 静止及 prescribed-motion solid；
* IBM constraint-load 的力与力矩诊断；
* constraint residual、液/气相 surface-band slip、法向/切向 slip 和
  divergence 等详细诊断；
* `alpha.water` extension、sharp reconstruction、PPMDF、IBM-aware
  projection、turbulence-wall treatment 等实验性开关。

这里的“可运行”不等于“边界条件已准确满足”。当前最稳妥的定位，是把它
作为后续重构与回归测试的 **cell-based development baseline**。

## 3. 已完成的主要数值实验

### 3.1 BF-1 与 IBM-R1

* BF-1：body-fitted monopile、双相 VoF、Stokes II、`kOmegaSST`。
* IBM-R1：规则背景网格、静止 IBM monopile、双相 VoF、Stokes II、
  `kOmegaSST`，使用旧 cell-based MDF 路线。
* R1 已运行到约 `480 s`。整体液面、`alpha.water` 与 Courant No. 保持稳定，
  多数观测量进入有界、近周期状态。
* IBM constraint-load 中，主导方向的 $F_x$ 和 $F_z$ 总体规则；$F_y$
  仍具有低频调制和缓慢增大的包络，但量级约为 $10^{-2}\,\mathrm{N}$。
* 个别近桩测点（例如 $x=10.05\,\mathrm{m}$）需要约 `240 s` 才接近新的
  周期状态，说明局部尾流/压力响应的时间尺度可远长于入射波周期。

### 3.2 slip 长程诊断

R1 的 slip 不是持续发散，而是进入了明显的周期状态：

* constraint residual 的周期峰值约为 $0.3\,\mathrm{m/s}$；
* surface-band slip 的典型周期峰值约为 $0.4$--$0.6\,\mathrm{m/s}$；
* 启动阶段气相一侧曾出现约 $2\,\mathrm{m/s}$ 的瞬态峰值；
* 切向 slip 明显大于法向 slip；
* maximum divergence 在启动后迅速下降，随后保持有界周期变化。

因此可以说当前模型具有较好的**长时间数值有界性和周期可重复性**，但不能
据此声称 immersed no-slip condition 已得到准确满足。周期收敛描述的是
数值状态不再漂移，而 slip 的绝对量级描述的是边界约束误差；两者是不同的
验证维度。

## 4. 原“向 VoF 追加 IBM”路线的 slip 局限

旧路线本质上是在已有 `interFoam`/PIMPLE 时间步中插入 IBM 处理：先完成
动量预测和 IBM velocity forcing，再由通量及压力修正恢复离散连续性。
问题在于，IBM 施加的速度约束和压力投影施加的 divergence-free 约束并非
作为一个统一系统求解。

于是可能出现以下循环：

1. MDF 把 forcing band 中的速度拉向结构速度 $\boldsymbol U_b$；
2. 后续 pressure/flux correction 为满足质量守恒再次改变速度；
3. 速度重新偏离 $\boldsymbol U_b$，形成 projection-induced slip；
4. 增加 MDF 次数能进一步压低某一步的残差，但不能保证压力修正后仍同时
   满足无滑移和不可压缩约束。

cell-based diffuse interface 还带来额外局限：

* 物理表面被扩展为若干 cell 厚的 forcing band；
* 几何位置、边界法向和强迫自由度都与背景网格绑定；
* 法向与切向约束容易受网格方向、band 厚度和权重影响；
* 两相交界处还存在密度和黏度跨越，forcing、压力和 VoF 通量之间更敏感；
* 增强强迫可能降低 slip，却可能恶化 divergence、载荷噪声或稳定性。

所以当前瓶颈不是单纯“再多做几轮 MDF”，而是**速度约束、面通量与压力
投影的离散兼容性**。

## 5. 已尝试但暂未成为主线的方案

### 5.1 PPMDF

PPMDF 在 MDF 过程中反复进行压力/通量投影。它计算代价很高，但现有实验
没有显示 slip 数量级得到相应幅度的改善。因此该功能值得作为研究对照保留，
不宜默认开启。

### 5.2 IBM-aware pressure projection

已经搭建了可选的 IBM-aware projection 原型，试图让压力修正感知固体区域
和 IBM 约束。初步实验同样没有把 slip 降低一个数量级。当前实现也不应等同
于完整的 pressure--IBM constraint coupled Schur solve，故保留为实验分支，
不作为默认路径。

### 5.3 新 turbulence-wall treatment

曾为 immersed `kOmegaSST` wall treatment 加入实验实现和诊断。早期版本
出现 coding failure，修复后得到的载荷与近桩响应仍不够健康。因此目前暂缓，
R1 基线继续关闭该功能。后续应在流体--IBM 主耦合可信以后，再单独验证
wall distance、$k$、$\omega$ 和 wall-function closure。

### 5.4 其他保留能力

* `sharpReconstruction`：cell-based sharp-interface 实验路线；
* `alpha.water` extension：改善固体邻域相分数取值，但不能单独解决 slip；
* IBM load calculation：目前主要反映 constraint/forcing load，正式 FSI 前
  仍需进行载荷守恒和与 body-fitted stress integration 的比较；
* one-way DPM：已留出预编译框架，但尚非当前验证主线。

## 6. 向 Constant--Pinelli marker-based 路线转向

下一阶段不是推倒 VoF、SDF、运动学和诊断系统重写，而是在同一
`ichiBoundaryFoam` 中替换 IBM 的核心耦合算子。目标流程为：

1. 从结构表面/SDF 零水平集生成并更新 Lagrangian markers；
2. 用离散插值算子 $J$ 将 Eulerian velocity 插值到 markers；
3. 计算 marker velocity 与 $\boldsymbol U_b$ 的残差及 Lagrangian force；
4. 用 spreading 算子 $S$ 将 marker force 分配回 Eulerian 网格；
5. 在 velocity--flux--pressure 迭代中同时修正边界约束和质量守恒。

这一路线的关键并非 marker 这一数据结构本身，而是：

* 表面自由度不再等同于 forcing cells；
* 插值和 spreading 能被明确构造成一对离散算子；
* 可以验证 partition of unity、合力/力矩守恒和离散伴随性；
* 为 Constant--Pinelli 式 velocity--forcing--pressure 迭代耦合提供基础；
* 减弱表面位置及强迫对具体背景网格方向的依赖。

SDF 仍然可用于 marker 定位、法向、固体内外判断和邻域搜索，但不再是唯一的
forcing-cell selector。

## 7. 顶层配置重构

配置现在先区分 `couplingMethod`，再区分 `forcingMethod`：

```text
ibm
{
    enabled          true;
    couplingMethod   cellBased;
    forcingMethod    diffuseVelocity;
}
```

当前计划支持的组合为：

| `couplingMethod` | `forcingMethod` | 定位 |
|---|---|---|
| `cellBased` | `diffuseVelocity` | 当前稳定基线 |
| `cellBased` | `sharpReconstruction` | 实验性 sharp 路线 |
| `markerBased` | `markerDirectForcing` | Constant--Pinelli 第一阶段原型 |

如未显式给出 `couplingMethod`，默认使用 `cellBased`，以保持旧 case 兼容；
不兼容的组合应尽早报错，而不是静默退化。

## 8. marker-based 路线的两层验证

### 8.1 第一层：不求解 N--S 方程的算子级测试

第一层不是使用 `potentialFoam`，也不是运行简化流动。应编写一个链接
OpenFOAM libraries 的小型 test utility：读取 `Time` 和 `fvMesh`，构造解析
Eulerian vector field，调用与 solver 完全相同的 marker generation、
interpolation 和 spreading 代码，然后计算误差并退出。

这种程序仍然使用 OpenFOAM 的 mesh、field、parallel communication 和 I/O，
只是没有时间循环和 PDE solve。`potentialFoam` 会引入额外的势流方程和边界
误差，反而不适合隔离验证 IBM 离散算子。

第一层至少包括：

* marker geometry：位置、法向、面积权重、总面积、平移和旋转更新；
* constant-field interpolation：验证 partition of unity；
* linear-field interpolation：在算子设计允许时检查一阶重构精度；
* spreading conservation：

$$
\sum_i \boldsymbol f_i V_i
\approx
\sum_l \boldsymbol F_l \Delta A_l
$$

* torque conservation：

$$
\sum_i \boldsymbol r_i\times\boldsymbol f_i V_i
\approx
\sum_l \boldsymbol r_l\times\boldsymbol F_l\Delta A_l
$$

* discrete adjointness/work consistency：

$$
\langle \boldsymbol u,S\boldsymbol F\rangle_E
\approx
\langle J\boldsymbol u,\boldsymbol F\rangle_L
$$

* 零场不产生虚假 forcing；
* marker 穿越 processor boundary 时，serial/parallel 结果一致。

当前 prototype 的 processor-local stencil、跨分区搜索以及 $J/S$ 的伴随性
仍未完成证明，因此第一层测试是进入完整 CFD 前的必要门槛。

### 8.2 第二层：逐级增加物理复杂度的 CFD 测试

在算子级测试通过后，依次进行：

1. 单相静水 + 静止 cylinder：检查零 forcing、零 slip 和零虚假流；
2. 单相 laminar cylinder：先低 Reynolds number 稳态，再检查阻力、升力和
   Strouhal number，并与 body-fitted 结果比较；
3. prescribed moving cylinder：检查运动学、added response、力和力矩连续性；
4. 双相静水 + 穿越自由面的静止 cylinder：专门检查密度比、VoF 与 IBM；
5. laminar Stokes II：与 V1 和 body-fitted case 比较；
6. `kOmegaSST` Stokes II：与 R1/BF-1 比较，第一轮关闭新 turbwall。

每一级都记录：

* marker slip 的 maximum/RMS、normal/tangential components；
* constraint residual 与 maximum divergence；
* `alpha.water` 的上下界和总体积；
* IBM force/torque 的连续性及与 body-fitted load 的误差；
* pressure iterations、wall-clock cost 和并行一致性；
* 至少两档背景网格和两档 marker spacing 的敏感性。

## 9. 下一步执行顺序

1. 冻结并保留当前 cell-based R1/BF-1，作为回归基线；
2. 将 marker generation、$J$ 和 $S$ 从 time loop 中拆成可复用组件；
3. 完成第一层 OpenFOAM test utility；
4. 修复跨 processor marker stencil，并验证守恒与伴随性；
5. 只在第一层通过后进入单相静止/层流 CFD；
6. 再逐步进入 moving body、双相 VoF、Stokes II 和湍流；
7. 主耦合稳定后，才恢复 turbwall、正式 load closure、DPM 和双向 FSI。

## 10. 当前结论

本阶段并非“旧 IBM 完全失败”。旧路线已经证明：VoF、波浪、SDF、静止/运动
结构、MDF、载荷及长程诊断能够在同一 solver 内稳定运行，并为新路线提供了
可重复的基线。其核心局限是，**有界且周期的 slip 仍然过大，而且通过增加
MDF、PPMDF、局部压力投影或临时 wall treatment 不能可靠地降低其数量级。**

因此下一阶段的合理重点，是从“在 `interFoam` 时间步后附加速度强迫”转向
“marker interpolation/spreading 与 velocity--flux--pressure 的一致迭代
耦合”，并先用两层验证体系证明离散算子本身正确，再增加双相、波浪和湍流
复杂度。
