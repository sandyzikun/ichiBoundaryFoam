# `ichiBoundaryFoam` 开发记录：Constant--Pinelli marker-based 算子与约束求解

日期：2026-11-14

## 今日结论

今天沿 Constant--Pinelli 式 marker-based IBM 路线完成了第一阶段离散算子
验证，并继续实现了 marker-space 速度约束求解。当前代码已经具备：

* 从 SDF forcing cells 投影生成表面 markers；
* processor-coupled 的 Eulerian-to-marker 插值算子 $J$；
* 与 $J$ 配对的 marker-to-Eulerian 转置展布算子 $S$；
* marker 面积权重及面积--体积加权的物理力展布；
* 常量场与线性场精确重构；
* 合力、力矩和离散功的守恒/伴随验证；
* matrix-free 求解 marker constraint equation

$$
J S\boldsymbol\lambda
=
\boldsymbol U_b-J\boldsymbol U,
$$

并由

$$
\delta\boldsymbol U=S\boldsymbol\lambda
$$

形成 Eulerian velocity correction。

串行、2 ranks 和 4 ranks 的算子测试均已通过。串行与并行的二次场插值误差
相同，说明此前 processor boundary 截断 stencil 引起的分区依赖已消除。

这里的“通过”仅表示 **marker 几何、插值、展布、守恒关系和独立约束求解器**
已经通过当前解析测试。完整 Navier--Stokes/VoF 流程中的 pressure projection
仍可能重新引入 slip，因此还不能说 Constant--Pinelli CFD backend 已完成验证。

## 初版测试暴露的问题

最初的 compact cosine interpolation 通过了常量场测试，但没有满足一阶矩：
线性解析场的最大误差约为 $1.56\times10^{-2}$。其结果还随 marker 相对网格
位置以及 MPI decomposition 改变。进一步加入二次场后发现，串行、2 ranks
和 4 ranks 的 RMS error 相差约 $5\%$。

失败原因包括：

1. 原始权重只做 partition-of-unity normalization，没有保证
   $\sum_iw_i(\boldsymbol x_i-\boldsymbol X_l)=0$；
2. marker stencil 从本进程的 `cellPoints/pointCells` 构造，在 processor
   boundary 处被截断；
3. 生产 correction 使用 normalized overlap spreading，但此前没有分别定义
   代数转置展布和物理面积--体积加权展布；
4. 最早的 torque test 用接近零的合力矩作为相对误差分母，产生了假失败。

因此，失败并非 OpenFOAM 或 MPI 环境误报，而是 tester 成功识别了初版算子
尚未完成的部分。

## 插值权重的一阶修正

在 compact cosine kernel 的基础上加入 affine moment correction。修正后的
权重满足：

$$
\sum_i w_{li}=1,
\qquad
\sum_iw_{li}(\boldsymbol x_i-\boldsymbol X_l)=\boldsymbol0.
$$

因此常量场和任意 affine-linear vector field 可在浮点误差范围内重构。当前
20 cells/方向的测试网格上：

* constant interpolation error：约 $2.5\times10^{-15}$；
* linear interpolation maximum error：约 $5.8\times10^{-16}$；
* maximum first-moment error：约 $2.4\times10^{-16}$。

二次场不要求精确重构，用于表征高阶误差。其 RMS error 为：

```text
serial : 0.00174756
2 ranks: 0.00174756
4 ranks: 0.00174756
```

## 跨 processor stencil 与反向累加

marker stencil 已改用 OpenFOAM v2312 的
`centredCPCCellToCellStencilObject`。该 point-connected stencil 自带
`mapDistribute`，能够收集 processor boundary 另一侧的 cell centres 和
Eulerian field values。

插值方向使用同一通信 map 收集远端值；展布方向交换 `subMap` 与
`constructMap`，并使用 `plusEqOp` 将多个进程对同一 owner cell 的贡献求和
返回。由此：

* marker interpolation 可访问跨分区支持域；
* raw transpose spreading 不丢失远端贡献；
* normalized correction spreading 的 overlap weight 也进行相同求和；
* physical force spreading 使用远端 cell volume，并将 force-density contribution
  正确返回 owner processor。

同时修复了 `maxSlip()`：旧实现直接用 distributed stencil label 索引 local
velocity field；现在统一调用 processor-coupled `interpolateMarkers()`。

## 面积权重、守恒与离散伴随

对于当前 capped cylinder，将 markers 分为侧面、正端盖和负端盖三组，并在
每组中平均分配对应解析面积：

$$
A_{side}=4\pi R L_{1/2},
\qquad
A_{cap}=\pi R^2.
$$

这里的等面积分配是当前第一阶段 surface quadrature；总面积严格匹配解析值，
但它还不是独立三角面 marker mesh 或局部 Voronoi 面积。以后对非均匀 marker
分布和一般几何仍需升级。

物理 force-density spreading 定义为：

$$
\boldsymbol f_i
=
\frac{1}{V_i}
\sum_l w_{li}\boldsymbol F_l\Delta A_l.
$$

当前测试结果为：

* analytic surface-area relative error：约 $5.7\times10^{-15}$；
* total-force conservation error：约 $1.6\times10^{-15}$；
* torque conservation error：约 $2.6\times10^{-16}$；
* area/volume-weighted adjoint error：约 $2.2\times10^{-16}$；
* raw algebraic transpose error：串行为零，MPI 中约 $10^{-16}$--$10^{-15}$。

torque error 现在使用

$$
(R+L_{1/2})\sum_l\Delta A_l|\boldsymbol F_l|
$$

作为 characteristic scale，避免解析净力矩接近零时得到没有意义的巨大相对误差。

## Marker-space constraint solve

算子测试通过后发现，生产 marker correction 仍只是将 marker residual 做一次
normalized spreading；这并不等价于解满足 no-slip constraint 的离散系统。
今天将其替换为 matrix-free preconditioned conjugate-gradient solve：

```text
r = Ub - J U
solve (J S) lambda = r
deltaU = S lambda
U <- U + deltaU
```

其中 $J S$ 不形成稠密矩阵。每次 matrix-vector product 只调用已验证的 raw
transpose spreading 和 processor-coupled interpolation。预条件器采用：

$$
M_{ll}^{-1}
=
\left(\sum_iw_{li}^2\right)^{-1}.
$$

新增 case 配置为：

```foam
markerConstraintTolerance              1e-8;
markerConstraintMaxIterations          300;
requireMarkerConstraintConvergence     false;
```

tester 使用更严格配置：

```foam
markerConstraintTolerance              1e-10;
markerConstraintMaxIterations          1000;
requireMarkerConstraintConvergence     true;
```

在解析 quadratic velocity input 上，结果为：

| 运行方式 | iterations | global residual | maximum marker residual |
| --- | ---: | ---: | ---: |
| serial | 259 | $1.17\times10^{-10}$ | $1.52\times10^{-11}$ |
| 4 ranks | 258 | $1.31\times10^{-10}$ | $1.69\times10^{-11}$ |

未预条件 CG 在 200 iterations 后停留在约 $5.7\times10^{-8}$；Jacobi
预条件并没有显著减少达到严格 $10^{-10}$ 标准所需的迭代数，但最终能够收敛。
这说明当前 $J S$ conditioning 仍是下一阶段需要关注的性能问题。

## 当前边界与下一测试节点

当前可以说：

> Constant--Pinelli marker-based 路线的第一阶段离散算子和独立 marker
> constraint solve 已在串行与 MPI 下通过验证。

当前还不能说：

> marker-based solver 已经在完整流动中满足 no-slip，或已经实现严格的
> coupled pressure--force Schur solve。

下一步必须进入第二层 CFD 验证，而不是继续只增加算子代码。第一项应为单相
静水中的静止 cylinder，检查：

1. 初始零场是否保持零 forcing、零 slip 和零虚假流；
2. marker correction 前后 $|J\boldsymbol U-\boldsymbol U_b|$；
3. ordinary pressure projection 后重新引入的 slip；
4. maximum/RMS normal 与 tangential marker residual；
5. divergence、face flux consistency 与 continuity error；
6. 每次 $J S$ solve 的 iterations、通信和 wall-clock cost；
7. serial/parallel 结果是否一致。

随后才应进入单相低 Reynolds number cylinder，并依据上述测试决定：

* 是否需要更好的 $J S$ preconditioner；
* 是否保留当前 predictor-only marker correction；
* 或进入 Constant--Pinelli 式
  `[marker forcing -> pressure correction]` sub-iteration，联合控制 boundary
  residual 与 continuity residual。
