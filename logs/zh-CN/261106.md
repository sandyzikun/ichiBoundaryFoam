# `ichiBoundaryFoam` 验证记录（2026-11-06）

## 原始两个 cases 的目的

`ichiBoundaryFoam-2phase-static-261104` 中的两个 cases 用于比较：

* `stokesII-control`：关闭 IBM 的 Stokes II 波浪基线；
* `stokesII-static-ibm`：相同波浪与网格中加入静止 SDF 圆柱，并执行
  四轮 multi-direct forcing（MDF）。

波周期和 ramp time 均为 `3 s`，算例运行至 `9 s`，即覆盖 ramp 和随后
两个周期。原始目标是检查：

* `alpha.water` boundedness；
* 相体积变化；
* Courant number；
* IBM slip 与 projection divergence；
* IBM 相对无障碍波浪基线造成的变化。

两个原始算例均正常到达 `9 s`。全程统计为：

| case | 全程最大 `alpha.water` | 末时刻 slip [m/s] |
| --- | ---: | ---: |
| control | 1.00280 | 不适用 |
| static IBM | 1.39537 | 1.80252e-2 |

因此该实验首先暴露了 IBM-enabled wave case 的明显相分数超界。

## forcing 与 alpha extension 验证矩阵

在不修改旧结果的前提下，新建：

```text
~/fastscratch/ichiBoundaryFoam-forcing-validation-261106/
```

使用当前最新版 solver，对相同 `9 s` Stokes II 工况运行五个 cases：

* IBM disabled control；
* diffuse forcing，alpha extension 关闭；
* diffuse forcing，alpha extension 开启；
* sharp reconstruction，alpha extension 关闭；
* sharp reconstruction，alpha extension 开启。

所有 cases 均正常结束：

| case | max alpha | phase range | final slip | max slip | max div |
| --- | ---: | ---: | ---: | ---: | ---: |
| control | 1.00280 | 0.005040 | 0 | 0 | 0 |
| diffuse / ext. off | 1.39537 | 0.006382 | 1.80252e-2 | 0.114416 | 3.46531e-8 |
| diffuse / ext. on | 1.40420 | 0.005994 | 3.77996e-2 | 0.0807969 | 2.52137e-8 |
| sharp / ext. off | 1.38967 | 0.006524 | 1.00660e-2 | 0.108151 | 3.29008e-8 |
| sharp / ext. on | 1.39618 | 0.006090 | 1.13580e-2 | 0.0466296 | 2.63234e-8 |

这里的 `phase range` 包含造波引起的周期变化，不能直接等同于长期质量
漂移。

主要结论为：

* sharp backend 将末时刻 slip 从约 `1.80e-2` 降至 `1.01e-2 m/s`，
  但没有消除 `alpha.water` 超界；
* alpha extension 降低了运行期间的 peak slip，却没有改善 alpha
  boundedness，并使末时刻 slip 略有增加；
* extension 不是当前超界的根本修复；
* 当前 sharp backend 仍只能视为稳定的开发入口，不能据此宣称已经
  复现 Ye et al.。

## 超界位置的空间定位

五个 cases 的全程最大 alpha 均出现在约 `t=7.25--7.30 s`。在
`t=7.25 s` 进行 cell-location 检查后发现：

| case | 全局 max alpha | 位置 | 圆柱区 max alpha |
| --- | ---: | --- | ---: |
| control | 1.00133 | 非入口区域 | 1.00065 |
| diffuse / ext. off | 1.38153 | `(0.02, 0.02, 0.385)` | 1.0 |
| diffuse / ext. on | 1.40420 | `(0.02, 0.02, 0.385)` | 1.0 |
| sharp / ext. off | 1.38909 | `(0.02, 0.02, 0.385)` | 1.0 |
| sharp / ext. on | 1.39612 | `(0.02, 0.02, 0.385)` | 1.0 |

`x=0.02 m` 是入口第一列 cells，而圆柱中心位于 `x=5 m`。因此目前
观察到的 `1.39--1.40` 峰值并不是直接发生在 immersed boundary 或
alpha-extension layer 上。

这一发现修正了此前的判断：相分数 extension 可能仍是完整两相
DF-IBM 所需的组成部分，但它与当前全局最大 alpha 超界并不位于同一
空间区域。

## wave inlet 与 active absorption

该工况在入口设置：

```foam
activeAbsorption yes;
```

OpenFOAM wave model 会根据入口实测水位向理论波速叠加 active
absorption correction。到 `t=7.25 s`：

* control 的入口水平速度约为 `-0.069 m/s`；
* diffuse IBM case 约为 `-0.166 m/s`；
* sharp IBM case 约为 `-0.171 m/s`；
* IBM cases 的入口 `phi` 约为 control 的 2.4 倍。

这表明圆柱引起的反射波到达入口后，active absorption correction 与
VoF inlet cells 之间发生了很强的反馈。它可能包含真实的反射波吸收
响应，但 `alpha>1.39` 本身显然不是可接受的物理解。

## 两个追加诊断 cases

### 关闭 MDF

`diffuse-no-mdf` 正常运行到 `9 s`：

* `max(alpha.water) = 1.36194`，出现在约 `7.42 s`；
* final slip 为 `0.170465 m/s`；
* max slip 为 `0.590029 m/s`；
* max divergence 为 `3.44448 1/s`。

关闭 MDF 后超界略有降低但仍然存在，而 slip 与 divergence 大幅恶化。
因此 MDF 不是入口超界的根源；它目前仍是维持 no-slip 和不可压缩性
所必需的修正。

### 关闭 active absorption

`diffuse-no-active-absorption` 未正常完成。它在 `t=8.96817 s` 的
`immersedPressureCorrection` 中出现 `NaN` 并退出：

* 退出前全程 `max(alpha.water) = 1.11562`；
* `t=7.5 s` 的最大值仍位于入口第一列；
* 随后负超界扩大到约 `min(alpha.water)=-0.0165`；
* pressure-correction GAMG 最终产生 `NaN`。

关闭 active absorption 明显减轻正超界，但没有形成稳定解。反射波不再
被主动吸收后，以负超界和 pressure-projection 失稳的形式继续积累。
所以简单关闭该选项不是修复方案。

## 当前判断与下一步

目前证据支持：

1. 圆柱附近 alpha 在已检查输出时刻保持 bounded；
2. 全局最大 alpha 出现在 wave inlet，而非 IB；
3. MDF 不是根因，但对 slip 与 divergence 至关重要；
4. active absorption 参与了入口正超界反馈，但直接关闭会导致另一种
   失稳；
5. 仅比较无障碍 control 与 IBM cylinder 仍无法区分：这是一般的
   obstacle-reflection / wave-boundary 问题，还是 IBM 特有的误差。

下一项关键验证应是相同几何、相同 Stokes II wave boundary 下的
body-fitted cylinder：

* 若 body-fitted case 也在入口产生相近超界，应优先修复反射波与
  active-absorption/VoF boundary 的兼容性；
* 若 body-fitted case 保持 bounded，而 IBM case 超界，则应检查 IBM
  对反射波、`phi` 和 pressure projection 的额外污染；
* 在完成该判别前，不应继续用 alpha-extension layers 或 MDF 次数去
  拟合当前峰值。

现有简单 body-fitted cylinder 验证网格的尺寸、坐标方向和本次自由液面
波槽并不一致，不能直接作为公平对照。需要新建与当前波槽、圆柱半径
及位置一致的 body-fitted mesh，或从正式 monopile body-fitted case
裁剪一个计算成本可控的二维验证版本。
