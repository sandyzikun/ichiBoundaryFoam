# `ichiBoundaryFoam` 下一阶段：从稳定的 “IBM-styled VoF” 基线寻找 MPhil 论文选题

日期：2026-11-15

## 1. 本文用途

本文不是新的数值方法已经成立的声明，也不是论文摘要。它用于下一阶段的
**文献 review 与选题讨论**：把目前真实可用的 solver、算例、验证证据和已知
局限完整交代给 ChatGPT 聊天模式，随后借助联网检索寻找一个兼具研究价值、
novelty、可验证性和 MPhil 时间尺度可行性的论文方向。

当前总目标是：

> 从已经能够长期稳定运行并达到周期状态的
> `interFoam`-like VoF + SDF/cell-based direct-forcing IBM 出发，选择一个
> 有清楚文献缺口的波浪--结构问题；只增加完成该研究问题所必需的开发，形成
> 可验证、可复现、可解释的成熟 MPhil 工作，而不是继续无限扩张 solver。

下文中的“IBM-styled VoF”是一个有意保守的称呼。现有程序确实具有 immersed
geometry、volume forcing、结构运动和相关诊断，但其 diffuse forcing layer、
近壁 slip、湍流壁面闭合和载荷定义仍有限制，不能把它直接等同于已经充分验证
的 sharp-interface/no-slip IBM。

## 3. 当前 “IBM-styled VoF” 已有 features

### 3.1 OpenFOAM 与 VoF 主体

`ichiBoundaryFoam` 基于 OpenFOAM-com v2312，流体主体沿用官方 `interFoam`
的维护代码路径，当前包括：

* 空气--水两相不可压缩 VoF；
* `alpha.water` 的 MULES 输运和界面压缩；
* 由 `p_rgh` 处理的重力、浮力和表面张力；
* PIMPLE pressure--velocity coupling；
* laminar 与 OpenFOAM turbulence model selection，包括现有算例使用的
  `kOmegaSST`；
* 固定时间步、Courant number、相体积、液面、速度和压力等现有诊断；
* 与已有 Stokes wave boundary condition、active absorption 和水槽模板兼容；
* 可选 dynamic-mesh/LTS 代码路径仍来自原 solver，但尚不是本项目已经专门
  验证的研究能力。

项目保留独立的纯 `interFoam` 回归编译形态：

```bash
make pure-interfoam
```

它不构造 SDF、geometry 或 IBM 对象，可用于判断新问题来自 VoF 主体还是 IBM
附加路径。回到正式开发版本时使用 `make ibm` clean rebuild。

### 3.2 波浪水槽能力

现有模板能够进行规则 Stokes waves 的生成、传播、吸收和结构相互作用研究，
主要工作配置为 Stokes II wave：

* 波高约 `0.16 m`；
* 周期 `2 s`；
* ramp time `4 s`；
* 主水槽和阻尼/吸收区来自长期使用的 `dampless-*` 系列模板；
* 已积累 body-fitted、IBM、laminar 和 RANS 对照算例。

早期也进行过 dam-break 及 Stokes I/II/V 与原生 `interFoam` 的回归或探索。
不过论文选题应以目前证据最完整的 Stokes II 基线为起点，除非文献缺口明确
要求改变波型。

### 3.3 SDF 几何表示

当前第一种正式几何是有限长 capped cylinder/monopile：

* case dictionary 配置中心、半径、长度和参考姿态；
* analytic signed distance function 区分固体内外；
* 可计算解析距离、外法向和局部刚体表面速度；
* 输出 `signedDistance`、`immersedSurfaceNormal` 和
  `immersedSurfaceVelocity`；
* SDF 随 prescribed motion 实时更新，背景网格不随结构运动。

目前不是任意 STL/复杂几何库，也不是多个结构通用框架。以多个 monopiles、
复杂浮体或任意海床为选题时，需要把几何扩展成本计入可行性评估。

### 3.4 Prescribed rigid-body motion

geometry 与 IBM enforcement 已分离。当前支持：

* static structure；
* `harmonic6DoF` prescribed motion；
* 三方向平移；
* roll、pitch、yaw 三方向旋转；
* 各方向独立的 amplitude、frequency 和 phase；
* rotation composition `Rz*Ry*Rx`。

运动规律为：

$$
q(t)=q_{ref}+A\sin\left[2\pi f(t-t_{ref})+\phi\right].
$$

这是**单向 prescribed motion**：流体感知结构的位置和速度，但流体载荷不会
反求结构加速度。因此当前可以研究主动运动、给定振荡或参数扫描，不能把结果
称为双向 6-DoF FSI。若选题要求 load-driven motion、弹性响应或 VIV 自激运动，
必须新增刚体/结构动力学耦合并单独验证。

### 3.5 当前稳定的 cell-based direct-forcing IBM

当前主线使用 SDF 和 cell/volume fraction 表示固体约束区。生产基线为：

```text
forcingMethod               diffuseVelocity
velocityBoundaryCondition   noSlip
multiDirectForcing          enabled
MDF pressure projection     disabled
IBM-aware projection        disabled
immersed turbwall           disabled in current R1 baseline
```

已有能力包括：

* diffuse immersed-solid weighting；
* 静止及 prescribed-motion surface velocity target；
* velocity predictor constraint；
* multi-direct forcing (MDF)；
* 与普通 PIMPLE pressure projection 的时间步耦合；
* forcing cells、solid cells 和流体 cells 的 SDF 分类；
* 等效 `immersedAcceleration` 及相关场输出；
* serial 和 120-rank large-wave-tank 工作流。

`sharpReconstruction` 后端也已存在，但只是向 sharp DF-IBM 发展的实验原型，
尚未实现完整的二阶 reconstruction、immersed flux treatment 或充分验证，不能
与生产基线等量齐观。

### 3.6 VoF--IBM 邻域处理

代码保留可选的 `alpha.water` solid-side extension：

* extension layers；
* distance/weight power；
* bounded alpha control。

它用于改善 immersed solid 邻域的相分数取值和界面连续性，但并不自动解决
velocity slip、mass conservation 或 contact-line physics。当前稳定 R1 基线应
明确记录该开关的实际状态，不能把“代码中有选项”误写成“物理模型已验证”。

### 3.7 Slip、连续性和边界层诊断

项目目前有比单纯“算例能跑完”更完整的 IBM diagnostics：

* weighted no-slip/constraint residual；
* maximum discrete velocity divergence；
* immersed-surface band 内总 slip；
* liquid/gas 分相统计；
* normal 与 tangential slip decomposition；
* 最大值位置、局部 `alpha.water` 和 signed distance；
* `immersedSolidFraction`、`immersedCellType`、surface normal/velocity 等场；
* 沿 cylinder 四个径向法线的 `--cylbound` profile。

`ichiwaveplot variables --cylbound` 可绘制：

$$
u_n,\quad u_\theta,\quad u_z,\quad
|\boldsymbol u_t|,\quad |\boldsymbol u_r|,
$$

并按 wave cycle/phase 对比离壁距离上的速度分布。现有结果显示中部侧面的法向
残差较小，主要误差来自 tangential slip；但全域 surface-band 最大值可能位于
自由液面、caps 或其他网格相位不利区域，不能以单条 profile 代替全域诊断。

### 3.8 IBM load accounting

当前可累积实际 IBM velocity correction 所对应的 constraint impulse，并输出：

* force 与 impulse；
* moment 与 angular impulse；
* 关于瞬时 body centre 的力矩；
* forcing-correction count。

该 load 是**IBM constraint load**，尚不是在解析 immersed surface 上分别积分
pressure 与 viscous stress 的完整水动力载荷。正式使用它研究 FSI、疲劳或载荷
系数以前，需要与 body-fitted surface-stress integration 做幅值、相位、网格和
守恒比较。

### 3.9 RANS 与 immersed turbulence-wall 原型

VoF 主体可以运行 `kOmegaSST`，IBM-R1 已进行长期 RANS 波浪--圆柱计算。
代码中另有第一版 SDF-based low-Re immersed turbulence-wall treatment：

* fluid-side SDF wall band；
* `k`、`nut` 向壁面阻尼；
* viscous-scale `omega` lower bound；
* liquid/gas 和 wall-band diagnostics。

但它没有替换 SST 内部依赖 mesh patch 的标准 `wallDist`，早期试验也没有得到
足够健康的载荷和近壁响应。因此当前 R1 production baseline 关闭该 treatment。
“运动结构在 `kOmegaSST` 下能否稳定运行”与“immersed RANS wall closure 已经
正确”是两个不同命题。

### 3.10 One-way DPM scaffold

代码有可编译的 OpenFOAM `basicKinematicCloud` one-way scaffold：

```bash
make ibm ENABLE_ONE_WAY_DPM=1
```

它可以让 passive particles 采样 VoF mixture 的 density、velocity、viscosity 和
gravity，但目前：

* 不向流体反馈 particle momentum/volume；
* 未限定 particles 只存在于水相；
* standard patch interaction 看不到 SDF cylinder，particles 可穿过 IBM；
* 未建立 sediment contact、bed packing、erosion/deposition 或 two-way coupling。

因此它目前适合 pathline/transport 原型，不是已经可用的 scour/DEM 模型。

### 3.11 Sampling、可视化与 HPC 工作流

算例已经形成较完整的数据链：

* wave gauges 和固定垂线 `lineX*`；
* surface elevation、surface velocity 和 corrected pressure；
* vertical velocity profiles；
* cylinder radial boundary lines；
* force histories；
* 2-D profile lattice；
* 可选近桩三维 observation box VTK export；
* `ichiwaveplot` 的 surface、vprof、cylbound、force 等后处理；
* Slurm、120-rank hierarchical decomposition、restart/rerun 模板。

body-fitted BF-1 的横向力已经出现明显低频对称性破缺。当前建议从现有
`120 s` checkpoint 重跑 `120--140 s`，并对近桩三维场进行较高频输出，以分析
约 `123.7 s` 的最大 $F_y$ 事件。这可以成为理解 wake instability 的证据，
但它本身还不是论文 novelty。

## 4. 当前主要算例与验证层级

### 4.1 Body-fitted reference

`dampless-rko-bf1/`：

* O-grid `blockMesh` body-fitted monopile；
* 真实 no-slip wall patch；
* Stokes II VoF；
* `kOmegaSST` 和标准 mesh-wall treatment；
* pressure/viscous force integration；
* 可作为 IBM 的流场、载荷和近壁 profile 对照。

BF-1 并非“绝对真值”：其 O-grid、第一层网格、wall functions、decomposition
和横向对称性破缺也必须做 mesh/time-step/symmetry 检查。

### 4.2 单相与 laminar VoF 基线

现有分层模板包括：

* L1：静止结构的单相 laminar IBM 基线；
* M1a：prescribed-motion 的单相测试；
* V1：静止 cylinder、laminar Stokes II VoF；
* V1m：prescribed pitch cylinder、laminar Stokes II VoF。

V1/V1m 保持相同网格、波浪、VoF、PIMPLE、IBM 和 sampling 配置；主要控制
变量是结构是否进行 prescribed harmonic pitch。V1m 为避免倾斜时 caps 进入
流体域，将 cylinder length 从 `1.2 m` 延长至 `1.6 m`，并从 `+5 deg`、零
角速度开始。这些是运动带来的必要伴随差异，论文中仍应如实报告。

### 4.3 RANS VoF 基线与下一测试

* R1：静止 IBM monopile、Stokes II VoF、`kOmegaSST`；
* R1m：计划中的 prescribed-motion RANS 对照。

R1 已运行到约 `480 s`，整体 VoF、Courant number 和主要信号长期有界，多数
观测量进入周期或近周期状态。V1/V1m 的重新运行用于先确认回档后的标准 binary
和运动路径；通过后才应进入 R1m，从而把运动与湍流模型的风险分开。

## 5. 已经得到的可靠认识

当前结果支持以下有限但重要的判断：

1. VoF、Stokes II、SDF、cell-based IBM、MDF、静止/规定运动结构和 120-rank
   工作流能够集成运行；
2. 静止 R1 可以长期有界，并形成周期或近周期响应，而不是持续数值发散；
3. 中部 cylinder 两侧的 radial profiles 保持良好镜像关系，说明当前 SDF、
   forcing 和 sampling transformation 没有显著破坏几何对称性；
4. 当前 immersed slip 主要是 tangential，而不是简单的 normal penetration；
5. body-fitted BF-1 自身出现强烈、间歇性的横向力/尾流对称性破缺；
6. motion kinematics 已通过小型 static/moving smoke test，V1/V1m 字典、网格
   topology 和 standard binary 路径已重新检查。

这些认识说明现有平台已经足以提出**物理问题导向**的论文，而不必先把 solver
改造成一种全新的通用 IBM。但论文结论必须避开当前方法尚未验证的近壁量。

## 6. 已知局限与不可过度声称的内容

### 6.1 No-slip 与 pressure projection 不完全兼容

当前 diffuse forcing 和普通 pressure projection 不是一个 monolithic constraint
system。MDF 可以减小某一阶段的 velocity residual，随后 pressure/flux correction
仍可能重新引入 slip。R1 长期稳定并不等于 no-slip 准确：

* 全域 surface-band slip 的周期峰值可达约 `0.4--0.6 m/s`；
* 中部侧线解析表面的总相对速度通常约 `0.013--0.055 m/s`；
* normal residual 明显更小，主要残差来自 tangential components；
* diffuse forcing 可能形成比真实 boundary layer 更厚的低速约束层。

因此当前不宜把 wall shear、skin friction、精确 boundary-layer thickness、局部
湍流生产或 separation point 作为无需额外验证的核心论文观测量。

### 6.2 当前 RANS wall treatment 不完整

标准 `kOmegaSST` 依赖真实 wall patch 和 `wallDist`。IBM-R1 虽可运行 bulk
RANS，但 immersed cylinder 并未天然获得与 BF wall 等价的 wall closure。
若论文核心依赖近壁 RANS physics，必须先解决或量化这个问题；若论文侧重
free-surface/wake/load 的相对趋势，则仍需用 BF、网格敏感性和远离 forcing band
的观测来限制结论。

### 6.3 载荷仍需正式 validation

IBM constraint load 与 BF pressure + viscous stress 的定义不同。可比较总力的
频率、相位、周期平均和趋势，但在完成系统验证前不应把二者的点对点差异全部
解释为物理效应。

### 6.4 当前不是双向 FSI、DEM 或 scour solver

* motion 是 prescribed，不由载荷驱动；
* cylinder 目前视为刚体；
* DPM 仅是 one-way scaffold；
* 没有 packed sediment bed、contact law、erosion/deposition 或 morphology；
* 没有经过验证的任意复杂几何与多结构支持。

选题若需要这些能力，应把新增实现和验证视作主要研究工作，而不是现成功能。

### 6.5 Marker-based 路线已经封存

Constant--Pinelli prototype 在规则小网格和串行短 CFD 中取得部分成功，但在
实际 120-rank L1 preflight 中暴露 compact stencil、distributed operator、
affine correction conditioning 和 reproducibility 风险。它不能用来支持当前
论文结果，也不应成为下一选题的默认前置开发任务。

## 7. 论文选题的实际需求

一个合适的 MPhil 题目应同时满足以下条件。

### 7.1 有明确、可用文献证明的 gap

不能只因为“本项目尚未做过”就称为 novelty。需要在论文中证明：

* 已有 wave--monopile / moving-cylinder / IBM--VoF 文献研究了什么；
* 哪种运动、尺度、自由液面效应、wake mode 或载荷问题仍缺乏系统研究；
* 现有实验、body-fitted CFD 和 IBM 各自缺少什么；
* 本项目的 geometry/motion/diagnostics 为什么恰好能够回答该问题。

### 7.2 Novelty 不应完全依赖重新发明 IBM

下一篇工作的 novelty 可以来自：

* 新的物理组合或参数区间；
* moving structure 与 nonlinear wave 的相位/频率耦合；
* wake symmetry breaking、低频 transverse loading 或 mode transition；
* 新的比较框架、诊断量或 reduced-order interpretation；
* 有针对性、可验证的小型数值扩展。

不应默认把“彻底消灭 slip”或重启 marker backend 作为论文开始的门槛。若某个
候选问题确实高度依赖 wall shear 或 exact no-slip，则应降低其优先级，除非
文献表明改进 wall treatment 本身就是可控且有价值的研究问题。

### 7.3 必须适合当前 solver 的可信观测量

优先选择对以下量敏感而对精确 wall shear 相对不敏感的问题：

* free-surface elevation and phase；
* far-/near-wake velocity away from the forcing band；
* vorticity/Q/Lambda2 structures，在网格敏感性后使用；
* dominant frequencies、phase relationships 和 symmetry measures；
* integrated load 的相对变化、频谱和周期平均，在 BF 校核后使用；
* prescribed-motion work/energy transfer，在 load definition 验证后使用。

### 7.4 工作量应符合 MPhil，而非完整博士项目

理想题目应主要复用现有水槽、圆柱、采样和 HPC 工作流，只增加一到两个清楚的
能力。以下组合风险过高：同时开发双向 FSI、任意几何、immersed wall model、
two-way DEM/scour 和新的 marker backend。

### 7.5 必须有可执行的 validation chain

最低要求应包括：

1. pure `interFoam` 或 BF 流体侧回归；
2. V1/V1m laminar 隔离测试；
3. R1/R1m RANS 对照；
4. 至少两档 mesh 或 forcing-band resolution；
5. time-step/phase sampling 检查；
6. 与公开 experiment、body-fitted CFD 或可靠 benchmark 的定量对比；
7. 明确区分 numerical symmetry breaking 与 physical instability；
8. 报告 slip、divergence、alpha boundedness 和计算成本。

## 8. 第一轮值得联网 review 的候选方向

这些方向只是检索起点，不能在检索前断言 novelty。

### A. Prescribed pitching monopile in nonlinear regular waves

核心问题可能是：给定小幅 pitch 的频率、相位和振幅如何改变 free-surface、
wake symmetry、横向力、主向力相位以及流体--结构功交换？

与现有平台的匹配度高：V1m/R1m 已有 prescribed pitch，主要新增工作是参数化、
载荷验证和 phase-resolved wake analysis。需要检索该问题是否已在 offshore wind
monopile、oscillating cylinder 或 wave energy 文献中被充分覆盖。

重点检索变量：

* motion frequency / wave frequency ratio；
* phase difference；
* pitch amplitude and pivot location；
* Keulegan--Carpenter number、Reynolds number、Ursell number；
* transverse force、wake mode、lock-in/phase locking；
* prescribed versus freely responding structures。

### B. Wave-driven wake symmetry breaking and low-frequency transverse load

BF-1 已观察到强烈、间歇性的 $F_y$ burst，R1 的横向响应则更小且具有不同
低频行为。潜在问题是：规则 Stokes waves 作用于理想对称 monopile 时，横向
对称性如何破缺、为何呈低频包络、其 onset 是否与 vortex modes、wave groups、
数值扰动或 turbulence closure 有关？

该方向物理意义较强，也可利用 `120--140 s` 的三维重跑。但必须特别严格地区分：

* 物理三维 instability；
* O-grid/decomposition/round-off 引入的 symmetry selection；
* RANS model 与 wall treatment；
* force sampling 或 restart artifact。

如果文献显示 regular-wave monopile transverse instability 已有成熟结论，本项目
需要寻找更窄的 novelty，例如 onset criterion、moving-pile modulation 或
body-fitted/immersed symmetry sensitivity，而不是重复展示一张非零 $F_y$ 图。

### C. Motion-modulated symmetry breaking

把 A 与 B 合并为一个较聚焦的问题：小幅 prescribed pitch 是否能够抑制、增强
或 phase-lock 原本间歇性的 transverse wake instability？

它可能形成清晰的静止/运动对照，并把 V1/V1m、R1/R1m 和 BF observation-box
数据串起来。风险在于结果可能高度依赖 RANS closure 和 load definition，因此
需要先完成静止 BF 对称性事件的复现，以及 moving BF 或独立文献 benchmark。

### D. Immersed RANS closure sensitivity for wave--monopile flow

研究问题可以是：在同一 VoF/IBM 框架下，bulk SST、SDF low-Re correction、
forcing-band thickness 和 grid resolution 如何影响 wake、load、slip 和 free
surface？

这是数值方法导向题目，可能具有清楚的工程价值，但开发与验证风险高。只有在
文献确认“VoF + moving immersed wall + SST closure”的缺口明确、且能够获得
可靠 BF/experimental reference 时才应优先。不能仅凭当前 wall treatment 原型
写成已经解决的问题。

### E. Phase-resolved Lagrangian transport around a moving monopile

利用 one-way particle scaffold 研究 prescribed motion 对无反馈 particles/pathlines
的输运、滞留和 near-bed exposure。它比完整 scour/DEM 可控，但必须先加入：

* water-phase-aware tracking；
* SDF-aware particle collision/interaction；
* 明确声明 particles 是 tracers 或 dilute inertial particles，而非 sediment bed。

只有当文献存在清楚的 transport gap 时才值得开发。若问题必须预测 erosion、
deposition 和 morphology，则当前平台离成熟成果仍太远，应降级为长期方向。

### F. 更复杂结构/结构群或 wave-current interaction

多桩干涉、偏航/倾斜 monopile、wave-current coexistence 和有限水深 nonlinear
effects 都可能有应用 novelty，但会分别要求 multiple geometry、inflow/current
validation 或新的参数空间。它们应作为文献检索备选，不应在评估开发成本前
直接选定。

## 9. 给 ChatGPT 聊天模式的联网 review 任务

把本文提供给聊天模式后，应要求它联网搜索，而不是只凭记忆列举论文。建议按
以下顺序工作。

### 9.1 建立 review 范围与术语表

检索至少覆盖：

```text
wave monopile transverse force symmetry breaking
regular wave cylinder wake instability lateral force
Stokes wave oscillatory flow vertical cylinder vortex shedding
prescribed pitching cylinder free-surface waves
oscillating monopile wave structure interaction pitch
moving immersed boundary VOF RANS cylinder
immersed boundary k omega SST wall treatment free surface
wave current monopile wake transverse load
Lagrangian particle transport oscillating cylinder waves
```

还应沿已找到论文的术语扩展，而不是固定使用本项目内部的 “IBM-styled VoF”。

### 9.2 优先查找和核对的来源

优先级建议为：

1. review papers 与近五年的论文，用于建立领域地图；
2. 经典 experimental benchmark；
3. 直接相关的 body-fitted CFD/LES/DNS/RANS；
4. VoF--IBM、moving boundary 和 immersed turbulence closure 方法论文；
5. offshore wind / coastal / wave-energy 应用文献；
6. 学位论文和会议论文用于追踪细节，但不能替代同行评议证据。

聊天模式应给出 DOI、期刊、年份和可访问链接，并核对题目、作者和结论，避免
生成不存在的引用。对于“没有人做过”这类强 novelty 判断，必须明确搜索范围和
不确定性。

### 9.3 为每个候选题建立 evidence table

每个候选方向至少记录：

| 项目 | 要回答的问题 |
|---|---|
| 已有工作 | 最接近的 5--10 篇论文做了什么？ |
| 缺口 | 缺的是物理组合、参数范围、方法还是验证？ |
| Novelty 强度 | 增量、清楚、还是可能已经被覆盖？ |
| 当前可复用能力 | 哪些 solver/case/diagnostics 可直接使用？ |
| 必需开发 | 具体要新增哪些代码，而非笼统说“做 FSI”？ |
| Validation | 可与哪些实验、BF 数据或 benchmark 比较？ |
| 可信观测量 | 是否避开当前 IBM 最薄弱的 wall-shear physics？ |
| HPC 成本 | 参数点、网格、模拟时长和存储大致多少？ |
| 主要风险 | 哪一步最可能使课题无法收尾？ |
| 最小论文版本 | 即使高级开发失败，最低可发表结果是什么？ |

### 9.4 不要让 review 偏离的问题

需要明确提醒聊天模式：

* 不要把 marker-based archive 当成当前可用 backend；
* 不要默认当前已经实现 two-way FSI；
* 不要把 one-way DPM 称作 scour/DEM；
* 不要把周期稳定误写成 no-slip 已验证；
* 不要只推荐“提高精度、做更多参数”而没有科学问题；
* 不要提出同时重写 IBM、RANS wall model、FSI 和 sediment 的超大课题；
* 不要仅凭关键词相似就宣称 novelty；
* 应优先寻找能利用现有 V1/V1m、R1/R1m、BF-1 和采样链的题目。

## 10. 候选题筛选方法

第一轮 review 后，可对每个题目按 1--5 分评分：

| 指标 | 权重建议 |
|---|---:|
| 文献 gap 的清晰度 | 25% |
| 与现有 solver 的匹配度 | 20% |
| Validation 可获得性 | 20% |
| MPhil 时间内的开发可行性 | 15% |
| 物理/工程意义 | 10% |
| 即使部分失败仍可形成成果 | 10% |

任何候选题若在以下任一项为 1 分，应谨慎淘汰：

* 没有可靠 reference/benchmark；
* 核心结论完全依赖当前不可信的 immersed wall shear；
* 必须先完成双向 FSI + 新 IBM + DEM 才能产生结果；
* novelty 只能表述为“以前没有用我们的 solver 做过”。

## 11. 建议的近期执行顺序

### 阶段 0：冻结和复核现有基线

1. 保持 `ichi` 在稳定 cell-based baseline；
2. 保存标准 binary hash、build flags 和 case commit；
3. 重跑 V1/V1m，确认 static/moving laminar VoF；
4. 在 V1m 通过后再建立/运行 R1m；
5. 重跑 BF-1 的 `120--140 s` 横向力事件并保存 phase-resolved 3-D flow field；
6. 不在选题确定前重新开启 marker backend 大开发。

### 阶段 1：两到三周的 focused literature map

1. 先比较候选 A、B、C，因其最能复用现有平台；
2. 同时快速评估 D、E、F 的开发风险；
3. 为每个方向建立 evidence table；
4. 找出最接近本项目的实验和 numerical benchmark；
5. 与 PI 确认物理问题和 novelty，而不是先确认要增加哪个 solver feature。

### 阶段 2：做最小判别性计算

对排名最高的两个候选题，各设计一个最便宜但能判别其价值的 pilot：

* 若选 moving monopile：只做少数 amplitude/frequency/phase 点；
* 若选 symmetry breaking：先复现事件、改变对称扰动/decomposition/mesh，确认
  它不是单纯数值 artifact；
* 若选 RANS closure：先在静止 BF/R1 上比较一个明确的 velocity/load metric；
* 若选 particles：先验证 water-phase 和 SDF collision，再谈 transport physics。

pilot 之后才冻结论文题目和完整 parameter matrix。

### 阶段 3：形成论文级 verification/validation matrix

应在正式长算前写清：

* hypotheses；
* independent/dependent variables；
* baseline and controls；
* mesh/time-step sensitivity；
* comparison data；
* uncertainty and failure criteria；
* storage、inodes 和 node-hour budget；
* plotting/analysis scripts and reproducibility record。

## 12. 当前最值得优先讨论的研究主线

在尚未完成联网 review 前，最符合现有能力与 MPhil 风险控制的暂定主线是：

> **规则 nonlinear waves 下，prescribed pitching monopile 对 wake symmetry、
> transverse loading 与 phase-resolved free-surface/velocity field 的调制。**

理由是：

* 静止、运动、laminar、RANS 和 body-fitted/IBM 对照基础大部分已经存在；
* prescribed motion 不要求立刻实现双向结构动力学；
* 可以把 BF-1 已观察到的 symmetry-breaking 事件与 V1m/R1m 联系起来；
* 主要观测可放在 phase/frequency/wake/free-surface 和 integrated-load trend，
  不必把未经验证的 wall shear 作为唯一结论；
* 新开发可以限制在 motion parameterization、三维观测、load validation 和
  symmetry metrics，而不是重写整个 solver。

但这只是**最先接受文献检验的 hypothesis**。如果联网 review 发现该组合已经
被充分研究，或当前 RANS/IBM 不足以支撑其关键结论，就应更换题目，而不是用
措辞包装成 novelty。

## 13. 希望聊天模式最终交付的结果

理想的联网 review 结果不是一串论文标题，而应包含：

1. 领域地图和术语；
2. 每个候选题的直接先例与明确 gap；
3. 可靠、可核对的 bibliography；
4. 候选题评分与淘汰理由；
5. 推荐的一个主选题和一个低风险备选题；
6. 一句可检验的 central research question；
7. 2--4 个具体 hypotheses；
8. 最小开发列表；
9. verification/validation matrix；
10. pilot simulations；
11. 预期 figures/tables；
12. 失败时仍能完成论文的 fallback scope。

最终题目应做到：**研究问题先于功能堆叠，证据先于 novelty 声明，验证范围与
solver 的真实成熟度相匹配。**
