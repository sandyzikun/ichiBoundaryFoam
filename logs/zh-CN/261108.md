# `ichiBoundaryFoam` 开发记录：V1/R1 初步通过长水槽试跑

日期：2026-11-08

## 今日结论

今天最重要的进展是：在关闭 MDF 内部反复压力投影（PPMDF）后，
`ichiBoundaryFoam` 已经分别完成了前 `20 s` 的

* `IBM-V1`：laminar、两相 VoF、静止 IBM 圆柱、`noSlip`；
* `IBM-R1-freeSlip`：`kOmegaSST`、两相 VoF、静止 IBM 圆柱、
  `freeSlip`。

两组算例均采用 Stokes II wave、固定 `deltaT = 0.001 s`、四次
predictor-level MDF，并保留一次常规 PIMPLE 压力修正。两组计算均正常
到达 `20 s`，未出现 OpenFOAM fatal error、自由液面失态或 VoF 全局崩溃。

这说明目前的两相 VoF、波浪边界、SDF 几何、静止 IBM forcing、MDF 和
常规压力速度耦合可以共同长时间运行。它是一个重要的开发里程碑，但尚不
等价于严格的 IBM 边界条件验证已经通过。

## V1 与 R1 的配置

| 算例 | 流动模型 | IBM 速度条件 | PPMDF | 用途 |
|---|---|---|---|---|
| V1 | laminar | `noSlip` | 关闭 | 两相 VoF 与完整速度约束基线 |
| R1-freeSlip | `kOmegaSST` | `freeSlip` | 关闭 | bulk RANS 与不可穿透 IBM 的实验性耦合 |

R1 暂时采用 `freeSlip` 是有意的。当前求解器尚未实现 SDF-aware wall
distance，以及 immersed `k`、`omega`、`nut` wall treatment。因而这组
R1 只能检验体相 `kOmegaSST` 与 IBM/VoF 的兼容性，不能用于验证单桩
近壁湍流、`yPlus`、壁面剪切应力或 no-slip RANS 载荷。

为了隔离湍流模型和速度边界条件的影响，模板 R1 随后已切换到
`noSlip` 并开始补充试跑；原先完成的 free-slip 结果已单独保留为
`dampless-ibm-r1-freeslip`。在本次记录检查时，新的 no-slip R1 尚处在
初始阶段，因此不能据此作长期判断。

## VoF、Courant number 与液面结果

V1 的主要数值范围为：

* 最大 domain Courant number：约 `0.414`；
* 最大 interface Courant number：约 `0.376`；
* 全程 `min(alpha.water)`：约 `-1.84e-10`；
* 全程 `max(alpha.water)`：约 `1.00675`，主要出现在启动阶段；
* 末时刻 `max(alpha.water)`：约 `1.00015`；
* Phase-1 volume fraction 范围：约 `0.55574--0.56414`。

R1-freeSlip 的主要数值范围为：

* 最大 domain/interface Courant number：约 `0.157`；
* 全程 `min(alpha.water)`：约 `-4.45e-11`；
* 全程 `max(alpha.water)`：约 `1.00536`，主要出现在启动阶段；
* 末时刻 `max(alpha.water)`：约 `1.00010`；
* Phase-1 volume fraction 范围：约 `0.55590--0.56433`。

V1 与 R1 的全局 Phase-1 volume fraction 非常接近，逐时刻平均绝对差约
`8.2e-5`，最大绝对差约 `4.3e-4`。在 `(9.5, 0, *) m` 等定点采样处，
水位和压力均保持规则周期变化，未观察到波形随时间失态。R1 的部分速度
曲线看上去比 V1 平滑，但由于两者同时改变了湍流模型和 IBM 速度条件，
目前不能把这一差异单独归因于 `kOmegaSST`。

位于两个 UUID workspace 中的对应 V1 与 R1 输入配置、关键数值日志和
输出图已经逐项核对一致。这验证了相同输入和共享 solver binary 下的
reproducibility；它不是两个独立 UUID solver build 之间的等价性验证。

## PPMDF 的成本与作用

PPMDF 是值得保留的可选诊断后端，但不适合默认开启。

旧 V1 PPMDF 与当前 V1 的 `20 s` wall-clock time 分别约为：

* PPMDF 开启：`51100 s`；
* PPMDF 关闭：`5503 s`。

PPMDF 在该算例中使运行时间增加到约 `9.3` 倍。关闭后，四次 MDF 只
约束 momentum predictor，随后仅执行常规 PIMPLE pressure projection。

不过 PPMDF 并非没有作用。V1 的 post-projection no-slip constraint
residual 统计为：

| V1 配置 | 后 `10 s` 平均值 | 全程最大值 | 末时刻值 |
|---|---:|---:|---:|
| PPMDF 开启 | `0.0573` | `0.282` | `0.140` |
| PPMDF 关闭 | `0.4365` | `0.633` | `0.386` |

因此，PPMDF 对 post-projection slip 有实质改善，但仍未将其压到
`slipTolerance = 1e-5`，不能视作根本解决方案。它目前更适合作为研究
pressure--forcing coupling 的对照，而不是日常生产设置。

## 压力投影后的 slip

当前日志反复显示：

* predictor MDF 后的 cell-centred constraint residual 接近机器零；
* 常规 pressure projection 后，constraint residual 再次出现。

V1 关闭 PPMDF 后的分段统计为：

| 时间段 | no-slip residual 平均值 |
|---|---:|
| `0--5 s` | `0.00329` |
| `5--10 s` | `0.304` |
| `10--15 s` | `0.443` |
| `15--20 s` | `0.430` |

R1-freeSlip 的法向不可穿透残差为：

| 时间段 | free-slip residual 平均值 |
|---|---:|
| `0--5 s` | `0.00110` |
| `5--10 s` | `0.0501` |
| `10--15 s` | `0.0359` |
| `15--20 s` | `0.0363` |

R1-freeSlip 没有表现出 V1 那样持续增大的趋势，但这两个 residual 约束的
速度分量不同，不能直接用数值大小评价两者优劣。另外，本轮 binary 未输出
真正的 immersed-surface slip distribution；当前统计仍是 solver 日志中的
cell-centred maximum constraint residual。后续需要结合新加入的 SDF band
详细采样再作表面验收。

## 当前问题是否构成 fatal blocker

目前的 post-projection slip 是明确的模型缺陷，但尚未演变为阻止项目继续
推进的 fatal failure：

* PDE 求解可以稳定完成；
* 自由液面保持规则；
* Phase-1 volume 没有失控漂移；
* `alpha.water` 的越界主要是启动阶段的小幅上溢；
* Courant number 保持在可控范围；
* V1 和 R1 均给出了可重复的 `20 s` 结果。

因此，在当前 PhD/IPAP 阶段，可以把它表述为一个已经被识别、量化并有
明确技术路线的长期研究问题，而不是声称 IBM 已经彻底失败。中期评估更
重要的是展示：问题在哪里、当前误差有多大、哪些物理结论暂时不能据此
给出，以及下一步怎样验证和改进。是否必须在 IPAP 前彻底消除该问题，仍
取决于学院和评审人的具体要求，不宜作绝对保证。

## 长期 pressure--forcing coupling 任务

当前 predictor MDF 和普通 pressure projection 分别满足 IBM 速度约束与
不可压缩质量守恒，但两个操作并不交换。简单地删除压力投影会破坏散度和
面通量；在压力投影后再次覆盖速度又会重新破坏质量守恒。

因此，速度约束与压力投影的平衡很可能会在一段时间内成为本项目的长期
开发任务。IBM-aware constrained projection、Lagrange multiplier、
augmented-Lagrangian 或其他 coupled/Schur-complement 路线与当前 SDF、
VoF 和 discrete forcing 总体方向并不必然冲突；它们主要替换或扩展的是
pressure--forcing coupling 后端，而不是推翻现有的几何表示、波浪模块和
两相 VoF 基础。

近期仍采用以下策略：

* 默认关闭 PPMDF，保留其编译选项和 legacy 对照；
* 同时记录 predictor 后和 pressure projection 后的 residual；
* 完成 no-slip R1 的 `20 s` 对照；
* 启用详细 SDF-band slip sampling，区分法向与切向误差；
* 在液面、Phase-1 volume、CFL 和 divergence 稳定的前提下继续开展
  IBM cylinder 的分级验证；
* 中期再评估是否需要实现真正的 IBM-aware constrained projection。
