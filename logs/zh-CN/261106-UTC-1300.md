# `ichiBoundaryFoam` 周进展与 IBM 技术路线梳理

记录时间：2026-11-06 13:00 UTC 左右。本记录综合 11 月 3 日以来的
实现、文献复审和验证结果。当前程序仍是研究原型；文中将已经通过的
基础回归、仅完成的短程烟雾测试和仍待验证的能力分开表述。

## 本周目标

项目目标是在 OpenFOAM-com `v2312` 的 `interFoam` 双相 VoF 框架中
加入可运动固体，为后续 monopile 单向 WSI、可信载荷重构及双向 6DoF
FSI 建立基础。当前优先事项不是立即求解结构动力学，而是先确保：

* IBM 关闭时保留 `interFoam` 的 VoF、PIMPLE/PISO 和波浪能力；
* 静止及预设运动结构能够由 SDF 描述；
* 速度约束、通量、压力投影和 VoF 输运之间不会相互破坏；
* 单相和两相验证均能区分数值稳定与物理正确；
* 最终载荷接入结构方程之前，先与 body-fitted 结果交叉验证。

## 技术路线的更迭

### 从移植 `sdfibm` 转为构建 `interFoam`-like solver

最初考虑直接移植单相 `sdfibm`。复审后改为从 OpenFOAM-com v2312
的 `interFoam` 求解路径出发，在保留双相 VoF 和 wave models 的前提
下加入 SDF 与 IBM。这样避免把单相 solver 强行扩展成两相系统，也为
后续 DPM、湍流和运动结构保留较清楚的模块边界。

IBM 关闭时已经完成的基础回归包括：

* 官方 `damBreak` 在 `t=0.1 s` 时，`U` 与原生 `interFoam` 完全
  一致，`p_rgh` 差异为零，`alpha.water` 最大差异为 `2.95e-19`；
* Stokes I/II/V 均能选择并完成一个周期；这些是 solver-to-solver
  regression，而不是独立的波浪物理验证；
* 同一 body-fitted cylinder 网格上，原生 `interFoam` 与关闭 IBM 的
  `ichiBoundaryFoam` 曾得到 `U` 最大差异 `3.53e-9 m/s`，圆柱阻力
  相对差约 `5.1e-9`。

### 从几何记录发展到 discrete-forcing IBM

解析 capped-cylinder SDF 用于计算结构内外、表面法向和刚体表面速度。
结构支持静止及 prescribed translation/rotation；这仍是单向 WSI，
尚未由流体载荷反求结构运动。

第一版在压力投影之后直接覆盖固体速度。虽然可以得到表面上近似零
slip，却会重新破坏不可压缩条件，并曾在短程 `damBreak` 测试中产生
`Max(alpha.water)≈1.098`。随后 forcing 被移到预测速度和压力投影
之前，流程调整为：

```text
常规动量预测
→ SDF-based velocity constraint
→ 从受约束速度构造通量
→ 全背景域压力投影
→ 同步得到 U 与 phi
→ 诊断 slip 与 divergence
```

该方案属于 **discrete/direct forcing IBM**。这里必须区分两个分类
维度：`discrete forcing` 描述边界约束如何进入离散方程；`diffuse` 或
`sharp interface` 描述固液界面如何表示。二者不是互斥术语。

### 采用连续压力场

按照 PI 提到的路线，当前压力 Poisson 方程不把 immersed boundary
作为内部压力边界，仍跨越包含虚构固体内部流体的完整背景域连续求解。
这一 `continuousPressure` baseline 实现简单且目前较稳定，但压力投影
会再次改变已受约束的速度，因此可能出现“散度很小而 slip 仍偏大”。

架构上仍为将来的 `pressureDecoupled` 后端留有空间。后者可在 IB
附近修改 pressure stencil 或施加等价的 pressure Neumann condition，
但目前尚未实现，不能把它写成现有能力。

### 加入 multi-direct forcing

为同时逼近 no-slip 与不可压缩约束，加入了可选 MDF：

```text
velocity forcing
→ continuous pressure-increment projection
→ correction of U, phi and p_rgh
→ slip evaluation
```

短程 Stokes II 烟雾测试中，一轮额外 correction 曾将末时刻 slip 从
`1.77e-2` 降至 `2.91e-3 m/s`，并将全域散度从 `1.30` 降至
`1.42e-9 1/s`。温和单相静止、平移和旋转测试也达到低 slip 和低
散度。MDF 因而保留，但当前每轮包含一次全域压力增量求解，计算成本
较高，也不能仅靠增加 correctors 取代界面与通量的一致离散。

### 从单一 diffuse interface 扩展为两种 forcing backend

当前两种 `forcingMethod` 均属于 discrete forcing：

* `diffuseVelocity`：diffuse-interface discrete forcing。通过 SDF
  构造的平滑固体指示量在有限厚度区域内约束预测速度；它是当前稳定
  baseline；
* `sharpReconstruction`：实验性的 sharp-interface discrete forcing
  入口。它使用二值 cell classification，并在流体侧第一层 forcing
  cells 作有界 SDF 插值。

第一版 sharp ghost extrapolation 曾造成指数发散，随后改为有界的
流体侧 reconstruction，短程测试可以稳定运行。不过当前 sharp 后端
尚未实现 Ye et al. 的二阶 Laplacian reconstruction、immersed-face
flux correction、完整并行 stencil 和可信 surface load，因此不能称为
已经复现 Ye et al. 的方法。

### 加入可选的 `alpha.water` 固体域延拓

参考 Ye et al.，加入了向固体内部逐层延拓 `alpha.water` 的选项，
用于近似满足 immersed surface 上的中性条件：

$$
\frac{\partial\alpha}{\partial n}=0.
$$

延拓值只服务于 IB 附近密度和动量离散，不应计入真实水体体积。当前
默认仍为关闭，因为在已有 diffuse-interface/continuous-pressure 组合
中，extension 没有改善全局 alpha boundedness：全程最大值由
`1.39537` 变为 `1.40420`，末时刻 slip 也有所增加。这不否定 Ye 等的
完整方法，只说明孤立移植 field extension 不能替代其 sharp velocity
reconstruction 与 flux coupling。

## 验证结果如何改变了问题判断

### 单相 IBM 数据通路基本稳定

温和全水域圆柱测试中，静止、预设平移和自转 IBM 均能完成。MDF 版本
典型末时刻 slip 为 `O(1e-5--1e-4) m/s`，散度为
`O(1e-12--1e-11) 1/s`，`alpha.water≈1`。这些结果支持 SDF、运动学、
速度约束和连续压力投影的数据通路，但尚未证明壁面空间精度、载荷或
高 Reynolds 数边界层已经正确。

### 两相长时间测试暴露入口相分数上溢

使用原 `linearUpwind grad(U)` 动量对流格式的 `9 s` Stokes II 对照
中，无 IBM control 全程 `Max(alpha.water)=1.00280`，而 static IBM
达到 `1.39537`。diffuse/sharp interface 与 alpha extension on/off 的
四种 IBM 组合都能运行完成，却均达到约 `1.39--1.40`，因此“没有 PDE
崩溃”不等于相分数解正确。

空间定位进一步发现，峰值位于入口第一列 cell
`(0.02,0.02,0.385) m`，而非圆柱或 alpha-extension layer。圆柱反射波
到达入口后，IBM cases 的入口速度修正与通量明显强于无障碍 control。
关闭 MDF 并未消除超界，却显著恶化 slip 和 divergence；关闭 active
absorption 虽降低正超界，却使负 alpha 继续扩大，并最终在压力修正中
产生 NaN。当前证据因此指向 obstacle reflection、active absorption、
入口 VoF 更新及全局流动响应之间的耦合，而不是单一 IBM layer bug。

### 重新采用 `limitedLinearV 1`

七周前 body-fitted WSI 曾在入口邻接 cell 出现负 alpha、负混合密度和
压力崩溃。当时通过把动量对流格式从

```foam
div(rhoPhi,U) Gauss linearUpwind grad(U);
```

改为

```foam
div(rhoPhi,U) Gauss limitedLinearV 1;
```

进行了稳定化。基于这一经验，当前项目已把 `limitedLinearV 1` 设为
后续 cylinder 与 wave validation 的默认基线；若改用其他格式，必须
作为独立数值实验明确报告。

早期短程 `1.5 s` Stokes II + IBM + MDF 测试在该格式下保持
`Min(alpha.water)≈-2.76e-20`、`Max(alpha.water)=1`，但这一时段尚未
覆盖反射波返回入口。

随后完成的最新 `9 s` 严格对照给出：

| case | 全程 min alpha | 全程 max alpha | 末时刻 max alpha | 末时刻 slip [m/s] | max slip [m/s] |
| --- | ---: | ---: | ---: | ---: | ---: |
| Stokes II control | `-2.67e-18` | `1.00210` | `1.00075` | 不适用 | 不适用 |
| static IBM + 4 MDF | `-2.65e-12` | `1.42534` | `1.01698` | `2.23634e-2` | `1.18979e-1` |

static IBM 的峰值仍出现在约 `t=7.30 s`；末时刻 divergence 为
`9.20e-9 1/s`，全程最大值为 `2.32e-8 1/s`。因此：

* `limitedLinearV 1` 继续作为更有界、更稳健的统一基线；
* 它没有单独解决当前长时间 multiphase IBM 的 alpha 上溢；
* 七周前的入口崩溃与当前问题具有相似失稳位置，但不能据此认定两者
  具有同一个完整根因；
* 下一步不能再用短程烟雾测试宣称 multiphase IBM 已经通过。

最新结果位于：

```text
~/fastscratch/ichiBoundaryFoam-2phase-static-limitedLinearV-261106/
```

因此旧数据应以本目录中的开发日志和结果表为归档依据。

## 当前技术路线的准确表述

当前默认研究路线是：

> OpenFOAM-com v2312 `interFoam`-like algebraic VoF
> + analytic SDF cylinder
> + diffuse-interface discrete velocity forcing
> + continuous pressure projection
> + multi-direct forcing
> + optional alpha field extension.

同时保留一个实验性的 sharp-interface reconstruction backend。当前
没有实现 pressure-decoupled IBM、守恒 cut-cell、完整 Ye-type sharp
DF-IBM、可信结构载荷或双向 6DoF FSI。

## 当前已经成立与尚未成立的结论

已经有证据支持：

* IBM 关闭时，基础 VoF 和 wave solver 路径基本复现 `interFoam`；
* SDF 可描述静止和 prescribed motion 圆柱，并实时更新 cell 分类；
* 单相温和测试中，连续压力与 MDF 可以同时获得低 slip 和低散度；
* 两种 forcing backend 均能完成短程两相计算；
* 长时间 alpha 峰值位于 wave inlet，而非已检查的 IB layer；
* MDF 对维持 no-slip 与低散度必要，但不是入口 alpha 上溢的根源；
* alpha extension 单独接入现有组合没有解决当前峰值；
* `limitedLinearV 1` 没有单独解决 `9 s` static multiphase IBM 超界。

目前仍不能声称：

* multiphase IBM 已达到可用于正式 monopile WSI 的验证水平；
* experimental sharp backend 等价于 Ye et al.；
* preliminary IBM volume forcing integral 是可信水动力载荷；
* moving two-phase fresh/dead cells 已满足守恒；
* `k-omega SST` 的 IB wall treatment 已完成；
* 当前程序已经支持由水动力驱动的双向 FSI。

## 下一步优先级

### 第一优先级：建立公平的入口问题判别

构造与当前波槽、圆柱尺寸、位置、波浪和边界完全一致的 body-fitted
cylinder 对照，并与 static IBM 使用相同的 `limitedLinearV 1`：

* 若二者均在入口产生相近超界，优先处理反射波、active absorption
  与 VoF inlet 的兼容性；
* 若 body-fitted 保持 bounded 而 IBM 明显超界，则重点检查 IBM 对
  反射波、`phi`、压力投影和相通量的额外污染。

应在日志中按 wave inlet、free surface、fluid、forcing layer 和 solid
分区统计 alpha、slip 与 divergence，避免只看全域极值。

### 第二优先级：使 forcing 与 immersed flux 离散一致

* 为 sharp backend 加入真实 boundary projection/image point；
* 实现并验证二阶 velocity reconstruction；
* 同步修正 forcing-layer 附近的 `phi` 与 VoF face flux；
* 补齐 processor-boundary reconstruction stencil；
* 比较 continuous-pressure 与未来 pressure-decoupled backend。

### 第三优先级：载荷与运动结构

* 为 forcing-volume load 加入固体内部虚构流体惯性修正；
* 实现 surface-stress reconstruction 或 moving control volume load；
* 与同分辨率 body-fitted cylinder 比较阻力、升力、相位及涡脱落；
* 为 moving two-phase fresh cells 实现守恒的 `alpha/U/p` 初始化；
* 在上述步骤通过后，再连接双向 6DoF 结构动力学。

### 第四优先级：monopile RANS 与 DPM

* 根据 SDF wall distance 和法向建立 SST-compatible IB wall treatment；
* 验证 `yPlus`、wall shear、`k`、`omega` 与 body-fitted 结果；
* 流体载荷和运动守恒通过后，再加入 Lagrangian sediment particles。

## 阶段判断

当前不需要放弃 SDF + DF-IBM，也不应立即全面转向 cut-cell。合理状态
是 **Go with conditions**：保留 diffuse-interface discrete forcing
作为稳定 baseline，继续发展 sharp reconstruction/flux coupling，
同时首先完成公平的 body-fitted wave-cylinder 对照。

在载荷重构、两相长时间 boundedness、moving conservation 和湍流壁面
处理通过之前，当前程序只应称为 IBM research prototype，不应用其
preliminary load 驱动正式的 monopile 双向 FSI。
